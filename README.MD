Plataforma Digital de Transporte Público

Plataforma web para la gestión de la tarjeta nacional de transporte público de Panamá (Metro y Metrobus). Permite consultar saldo, recargar en línea, ver el historial de transacciones y pagos de pasaje, solicitar beneficios o descuentos y administrar cuentas familiares.

Proyecto semestral de Lenguajes de Programación Maestría en Ciencias Computacionales, Universidad Tecnológica de Panamá, II Semestre 2026 Profesor: José Chiru
